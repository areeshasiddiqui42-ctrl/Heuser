# The Creative Desk — Portfolio starter

## Files
- `index.html`: interactive desk homepage
- `about.html`, `projects.html`, `creativity.html`, `achievements.html`, `future.html`: separate portfolio pages
- `style.css`: layout, colours, fonts, responsive styling and animations
- `script.js`: small JavaScript interaction
- `images/`: put your own portrait here

## Before publishing
1. Add your own image at `images/your-photo.jpg`.
2. In `index.html`, replace `https://YOUR-USERNAME.github.io/YOUR-REPO/CS_CRP/Homework_7/` with your actual Homework 7 live URL.
3. Replace the sample text and achievement placeholders with accurate personal details.
4. Test every page and link locally.
5. Upload the folder contents into your Heuser repository under `CS_CRP/Homework_8/`.
6. Enable GitHub Pages for the repository/branch and confirm the live URL.

This is a static HTML/CSS/JavaScript website. It does not need a server or database.
